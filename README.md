
 # 🍔 Sukoon Bites – Online Food Ordering Website

> **Good Food, Good Mood.**

Sukoon Bites is a modern and responsive online food ordering website developed as a college web development project. It provides a simple platform where customers can explore food items, add products to their cart, place demo orders, and track their order status.

The project also includes an Admin Panel for managing food items, orders, customers, and store settings.

## 📌 Project Overview

- **Project Name:** Sukoon Bites
- **Project Type:** Online Food Ordering Website
- **Technology:** HTML, CSS, JavaScript, Bootstrap
- **Data Storage:** Browser LocalStorage
- **Project Architecture:** Frontend-based Multi-Page Web Application

This project is developed using frontend technologies. It does not require a backend server or database installation. Data is stored in the browser using LocalStorage.

## ✨ Features

### 👤 Customer Panel

- Responsive and user-friendly homepage.
- Customer registration and login.
- Food menu with multiple categories.
- Search and filter food items.
- Veg and Non-Veg filters.
- Sorting by price and ratings.
- Add items to shopping cart.
- Increase or decrease item quantities.
- Apply promotional coupon codes.
- Automatic bill calculation with delivery charges and GST.
- Demo checkout with COD and UPI options.
- Generate unique order IDs.
- Track order status.
- View previous orders.
- Manage customer profile.

### 🔐 Admin Panel

- Separate Admin Login.
- Admin Dashboard with statistics.
- View total orders, users, dishes, and revenue.
- Add, edit, and delete food items.
- Manage food availability.
- View and manage customer orders.
- Update order status.
- View registered customers.
- Manage restaurant settings.
- Reset demo data.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Extract the project folder if downloaded as a ZIP file.
3. Open the project folder.
4. Double-click `index.html`.
5. The website will open in your browser.

**To access the Admin Panel:**

Open `admin/admin-login.html` in your browser.

No backend server, database, or additional installation is required.

## 💾 Data Storage

This project uses browser **LocalStorage** to store and manage data.

Some of the stored data includes:

- Food items
- Customer accounts
- Shopping cart
- Orders
- Restaurant settings

The customer website and Admin Panel use shared browser storage to reflect changes across pages.

**Note:** This is a frontend demonstration project. LocalStorage is not a secure replacement for a production database, and the login and payment flows are for demonstration purposes only.
